# Datenschutzerklärung für Fussballschau24

Stand: Juni 2026

Fussballschau24 ist eine Fußball-App für Live-Ergebnisse, Tabellen, Vereins-News und Push-Benachrichtigungen.

## Erhobene Daten

Die App kann folgende Daten verarbeiten:

- Geräteinformationen
- Push-Benachrichtigungs-Token (Firebase Cloud Messaging)
- Favoriten-Einstellungen (lokal auf dem Gerät gespeichert)

## Verwendung der Daten

Die Daten werden ausschließlich verwendet, um:

- Push-Benachrichtigungen bereitzustellen
- Favoriten zu speichern
- Funktionen der App bereitzustellen

## Weitergabe von Daten

Es werden keine personenbezogenen Daten verkauft oder an Dritte weitergegeben.

## Drittanbieter

Die App verwendet folgende Dienste:

- Google Firebase Cloud Messaging
- API-Football
- GNews API

Für diese Dienste gelten die jeweiligen Datenschutzbestimmungen der Anbieter.
