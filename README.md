3. Verarbeitete Daten

Beim Verwenden der App können technisch erforderliche Daten verarbeitet werden:

• Geräteinformationen
• Betriebssystemversion
• Push-Benachrichtigungs-Token
• App-Fehler- und Verbindungsinformationen
• Lokal gespeicherte Favoritenvereine

Die App erstellt keine Nutzerprofile und verkauft keine personenbezogenen Daten.

4. Push-Benachrichtigungen

Für Push-Benachrichtigungen verwendet die App Firebase Cloud Messaging (FCM) von Google.

Dabei wird ein technisches Geräte-Token verarbeitet, um Benachrichtigungen an das jeweilige Gerät zustellen zu können.

Weitere Informationen:
https://firebase.google.com/support/privacy

5. Lokal gespeicherte Daten

Ausgewählte Favoritenvereine werden lokal auf dem Gerät gespeichert.

Diese Daten dienen dazu, Favoriten und Benachrichtigungseinstellungen innerhalb der App bereitzustellen. Favoriten können durch den Nutzer jederzeit geändert oder entfernt werden.

6. Verwendete Drittanbieter-Dienste

Die App verwendet folgende externe Dienste:

• Google Firebase
• Firebase Cloud Messaging (FCM)
• API-Football
• GNews API

Diese Dienste können technische Informationen verarbeiten, die für die Bereitstellung der Inhalte erforderlich sind.

7. Zweck der Datenverarbeitung

Die Verarbeitung erfolgt zur:

• Bereitstellung von Fußballergebnissen
• Anzeige von Tabellen und Vereinsinformationen
• Anzeige von Nachrichteninhalten
• Zustellung von Push-Benachrichtigungen
• Technischen Bereitstellung und Stabilität der App

8. Weitergabe von Daten

Es erfolgt keine Weitergabe personenbezogener Daten zu Werbe- oder Marketingzwecken.

9. Speicherdauer

Lokal gespeicherte Favoriten bleiben auf dem Gerät gespeichert, bis sie vom Nutzer gelöscht oder durch Deinstallation der App entfernt werden.

Push-Benachrichtigungs-Token werden verwendet, solange Benachrichtigungen aktiviert sind oder technisch erforderlich bleiben.
